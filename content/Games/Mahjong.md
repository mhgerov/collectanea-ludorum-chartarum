## Equipment
- 144 tiles 
## Setup
- Dead wall of 16 tiles
## Scoring
### Base Points
1. Count sets
	1. Chow = 0 pts
	2. Pong = 2 pts
	3. Kong = 2 pts per tile = 8 pts
	4. Noble x2
	5. Concealed x2
	6. Eyes - dragon, round wind, seat wind = 2 pts
	7. Flowers = 4 pts
2. Round up to nearest 10 pts
3. Add +30 pts

|                 | Simple | Noble |     |
| --------------- | ------ | ----- | --- |
| Chow            |        |       | 0   |
| Pong            | 2      | 4     |     |
| Pong, Concealed | 4      | 8     |     |
| Kong            | 8      | 16    |     |
| Kong, Concealed | 16     | 32    |     |
| Flowers         |        |       | 4   |
